# Pattern sources

Additional embedded RLE patterns are based on the corresponding ConwayLife LifeWiki pattern pages.

- Figure Eight: https://conwaylife.com/wiki/Figure_eight
- Kok's Galaxy: https://conwaylife.com/wiki/Kok%27s_galaxy
- Loafer: https://conwaylife.com/wiki/Loafer
- Copperhead: https://conwaylife.com/wiki/Copperhead
- Simkin Glider Gun: https://conwaylife.com/wiki/Simkin_glider_gun

The application parses these compact RLE definitions through the existing `RleParser` at startup.
