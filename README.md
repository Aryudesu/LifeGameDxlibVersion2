# LifeGameDxlibVersion2

DxLib を使用した Conway's Game of Life の Version 2 です。

旧 `LifeGameDxlib` の機能を段階的に移植しつつ、盤面表現やアプリケーション構成を整理しています。

## 現在の主な機能

- 1536 x 1536 の盤面
- Conway の Life Game (B3/S23)
- 上下左右が接続するトーラス境界
- `std::uint64_t` を用いた BitBoard と 64 セル単位の bit-parallel 世代更新
- DxLib による 1024 x 1024 描画
- 停止 / 再開 / 1世代送り
- ランダム初期配置とランダム再生成
- ランダム生成時の生存セル密度を 10 / 20 / 30 / 50% から選択
- 停止中のマウスによるセル編集
- キーボードおよびマウスによるカメラ移動・ズーム
- `.ary2` 形式での保存 / 読込
- 世代数・FPS・シミュレーション速度・ランダム密度・生存セル数・生存率の画面表示
- 60 FPS を目標とした描画と、描画から独立した世代更新速度

## 操作

| 操作 | 内容 |
| --- | --- |
| Enter | 停止 / 再開 |
| Space | 停止中に1世代進める |
| Delete | 盤面をクリアして停止 |
| R | 選択中の密度で盤面をランダム再生成し、Generation を 0 に戻す |
| 1 / 2 / 3 / 4 | ランダム生成密度を 10 / 20 / 30 / 50% に変更 |
| G | グリッド表示切替 |
| 矢印キー | カメラ移動 |
| Shift + ; / + | ズームイン |
| - | ズームアウト |
| マウスホイール | カーソル位置を基準にズーム |
| 中ボタンドラッグ | カメラを掴んで移動 |
| 左 / 右ドラッグ | 停止中にセルを生 / 死へ編集 |
| PageUp | シミュレーション速度を上げる |
| PageDown | シミュレーション速度を下げる |
| Ctrl + S | 保存 |
| Ctrl + L | 読込 |

`R` によるランダム再生成では、停止 / 再生状態と選択中のシミュレーション速度はそのまま維持されます。
ランダム生成密度の初期値は 20% で、現在の選択値は HUD に表示されます。
HUD の `Alive` には現在の生存セル数と盤面全体に対する生存率が表示されます。

シミュレーション速度は `1 / 5 / 10 / 30 / 60 / 120 / 300 / 600 gen/s` から選択できます。初期値は 60 gen/s です。

## ビルド

Visual Studio の x64 Debug / Release を用意しています。

DxLib の参照先は MSBuild プロパティ `DxLibDir` で変更できます。未指定時は以下を使用します。

```text
C:\DxLib_VC\プロジェクトに追加すべきファイル_VC用
```
